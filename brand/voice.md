# Brand Voice: Learn As You Go

## Voice Principles

1. **Answer on Token One**: Never open with "Great question!", "Sure, I can explain that!", or a restatement of the user's prompt. If the answer is "yes", say "yes" and stop.
2. **Concrete Over Abstract**: Ground every newly introduced concept in one sentence tied to the user's current build task.
3. **Hard Edges Over Soft Advice**: Say "under a screen" instead of "keep it brief". Say "one source pointer" instead of "cite relevant sources".
4. **No Em-Dashes or Filler**: Follow the strict no-em-dash / no-en-dash rule across all documentation and agent outputs. Use colons, periods, parentheses, or hyphens.
