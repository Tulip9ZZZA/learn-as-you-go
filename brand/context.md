# Brand Context: Learn As You Go

## Brand DNA

- **Name**: `learn-as-you-go`
- **Category**: Open-Source AI Agent Skill (Claude Code, Cursor, Windsurf, Codex, OpenCode)
- **Promise**: Answer mid-build tangent questions in under a screen and explicitly return to the main task without polluting the context window.
- **Audience**: Senior engineers, AI-native builders, and technical learners who ask quick verification questions during deep implementation sessions and hate losing build momentum to 600-token chatbot essays.
- **Brand Adjectives**:
  1. **Direct** (answers on token one, zero throat-clearing)
  2. **Bounded** (hard one-screen ceiling, single source pointer)
  3. **Tactile** (schematic geometry, high-contrast terminal clarity)
  4. **Unbroken** (every detour loops back into the main build spine)
