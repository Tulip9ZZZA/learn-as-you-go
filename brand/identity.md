# Visual Identity Brief: Learn As You Go

## 01 - Identity Strategy Statement

`learn-as-you-go` visually embodies a tight detour that closes cleanly. Rather than using generic AI sparkles, chat bubbles, or academic graduation metaphors, the identity uses schematic railway and circuit-routing geometry: a straight vertical build track in Return Emerald (`#10B981`) paired with a compact 45-degree tangent loop in Signal Amber (`#F59E0B`) that branches out to an answer node and immediately merges back into the main spine.

## 02 - Logo Direction

- **Primary Mark ("The Loopback Detour")**: A 256x256 geometric symbol built on an 8px grid with 22-24px rounded strokes. The left vertical spine represents the unbroken main task (`Back to <task>`); the right rounded loop represents the bounded side-answer (`Answer first`).
- **Wordmark**: Constructed pure-path geometric uppercase letterforms (`LEARN-AS-YOU-GO`) with zero live `<text>` dependencies in logo files, guaranteeing identical rendering across every OS and SVG engine.
- **Small-Size Cut (`favicon.svg`)**: Thickened 26-28px strokes and enlarged outer spark node so the loop and spine remain unmistakable at 16x16px and 32x32px.

## 04 - Typography

- **UI & Headlines**: System sans stack (`-apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, sans-serif`), weight 700-800, tight tracking (`-2px` on hero titles).
- **Code, Triggers & Pointers**: System monospace stack (`ui-monospace, SFMono-Regular, Menlo, monospace`) for terminal proofs, command snippets, and status badges.
