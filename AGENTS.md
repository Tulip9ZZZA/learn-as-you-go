## Agent skills

- **Side-answers (`learn-as-you-go`)**: When the user asks a mid-build tangent question ("quick question", "by the way", "what's X?"), answer in under a screen, ground new terms in the active task, cite one pointer, and end with `Back to <task>. <next step>`. See `skills/learn-as-you-go/SKILL.md`.
- **Domain docs**: Single-context repository. Read `GLOSSARY.md` and `docs/adr/` before modifying skill rules or scripts. See `docs/agents/domain.md`.
- **Issue tracker**: GitHub Issues (`gh`). See `docs/agents/issue-tracker.md`.
